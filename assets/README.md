# Battle Box media assets

Put reusable assets here. Do not commit copyrighted music or large RAW files.

Recommended structure:

```text
assets/
  sfx/
    score.wav
    miss.wav
    whoosh.wav
  overlays/
    win.png
    fail.png
  fonts/
    README.txt
```

V0.3 does not require these files: the default style is rendered programmatically by Remotion. The folder is reserved for the next style pass with Battle Box-specific SFX and PNG overlays.
